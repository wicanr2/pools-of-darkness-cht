# 025 直接攔截繪圖與前端命令

狀態：像素出口、單次RGB合成及限定8×8字模整段CONFORMED，其餘常式未知。Issue：[#45](https://github.com/wicanr2/pools-of-darkness-cht/issues/45)、[#46](https://github.com/wicanr2/pools-of-darkness-cht/issues/46)。

使用者於2026-10-25要求完全攔截繪圖函數，避免先畫原版底圖再覆畫HD，並指定參考`/home/anr2/cht/mm3`。
方向已授權；本規格先補本作輸出契約，未達READY的原型不接正式路徑。

## 目標與證據入口

參考mm3的`docs/spec/075-direct-render-commands.md`：繪圖入口轉成型別化命令，由呈現後端選原版或HD。
命令表達來源、幀、來源矩形、目的表面、裁切、鏡像及順序；原版需要的索引資料與後續讀回保留相容契約。
前輪讀到的mm3規格仍在DRAFT。2026-10-26使用者另指定`docs/re/direct-render-methodology.md`，
該新版已完成限定圖片常式接管、事件預算與原子效果提交；本作只沿方法，位址與機器效果仍須獨立驗證。
本作原版證據與來源定位見[研究019](../re/019-draw-interception.md)。

## 待證契約

- 本作每個繪圖入口的原始bytes、呼叫參數、來源與目的、裁切／鏡像、返回及重入。
- 暫存器、旗標、堆疊、完整RAM與畫面外寫入，以及後續畫面讀回與視窗還原。
- 8086像素迴圈改由已驗候選處理後的虛擬步數、計時器、音訊與輸入事件邊界。
- 直接命令的原版RGB、HD選擇、遮擋、清除、部分更新與切換生命週期；未知呼叫回退原版。
- 原版與候選的同狀態比較、獨立RGB及成對效能，另跑正常DEMO與既有讀檔／存檔抽樣。

正式層只放本作入口與參數辨識，共通CPU／DOS機制若需擴充，先在隔離clone另立通用規格，不加本作常數。
不改磁碟原版資料、存檔格式、美術風格、倍率或語系操作，不修改mm3或dosgolem原始工作樹。
正式範圍逐條達READY及CONFORMED；不以一個可行原型外推全部繪圖，不預告固定FPS倍數。

## 已定位像素出口與單次RGB合成

狀態：CONFORMED。先依十個實際像素出口、IDA原始指令、既有CPU原子邊界及中央圖面opaque逐件審查為READY，再實作並完成下列驗收。
先接管已觀測MOVS／STOS像素出口；原函式其餘計算與返回照原指令執行，完整函式空跳過不在此分支。
原版證據為[019-draw-writers.json](../re/019-draw-writers.json)與研究019的IDA段匯出。

1. 通用層新增預設關閉的mode13h原生字串寫入與不可變繪圖命令。8／16位MOVS、STOS及REP／非REP，前後向分開驗；32位、跨段環繞、MMIO讀取及未驗監看回退原指令。
2. 命令包含COPY／FILL／PIXEL、來源色號資料、目的位移、大小／方向、順序與原CS:IP／步數。命令後端不讀DOS狀態；索引相容背板維持原版讀回及存檔行為。
3. 字串指令仍佔原來的一個Machine.Step；prefix／string iteration與DOSBoxCost週期和原實作相同，不跨過原有指令事件邊界，不以略過函式縮短虛擬時間。
4. 本作前端維護命令索引畫布，每次retrace與原版索引獨立比對。模式切換另作顯示邊界；未知寫入仍轉PIXEL記錄，不漏掉相容路徑。
5. 最終RGB先確定HD／文字／保留格，未覆蓋像素才取原版色盤填入。保留層以不可變索引＋色盤來源處理原版比較與歷史像素，不先建整張原版RGB再覆畫HD。
6. alpha0僅作內部未填原版標記，最終RGBA仍全不透明。半透明或未知圖層回原合成路徑；既有opaque圖、字型、選單、片頭字幕與面板順序不變。

驗收包括原指令／原生指令的暫存器、旗標、完整RAM、索引、色盤、週期、逐點寫入通知、計時／輸入事件及拒絕條件；
原與延後填色的Hold／Latch、歷史原版像素、切換與負對照；正常DEMO四路、既有讀檔／存檔及閃現量尺。
以填色計數證明已選HD像素沒有先填原版RGB，另做成對成本量測。測試與原版輸入均留可重生收據。

程式來源`c0fc72b23476d695e2ca46d3431cf2fa9a9d54b6`，執行檔SHA-256
`2b5bdaa2c6c4bdd3746108ed30e46db065f3a928b1a90a911c01e7de298deb81`。
共通規格434／435及前端測試通過；正常DEMO十個出口3343240次寫入全部原生，8633次回掃畫布失配0。
完整CPU／RAM、十份固定日期的記憶體／堆疊見證、音訊與DOS事件、127檔成對一致，四路視窗終點及獨立HD像素核對通過。
讀檔、片頭與封面三條正常路線39對截圖同舊合成；原版規則、索引讀回與存檔不改。
全幅HD封面原版RGB填色0；BIGPIC只填原版外圍。半透明主題及未知命令的安全回退另驗。

收據與重生工具入口統一見[研究019](../re/019-draw-interception.md#已驗接入)。
量尺對玩家主動F2切換的998個記錄逐筆分類，不能宣稱該份原始計數為0；其他已列穩定模式／正常路線原始計數0。
本規格不把保留原版索引背板稱為消除所有原版繪圖指令，也不把局部CPU合成成本換算成遊戲FPS。

## 整段繪圖常式的事件預算替換

狀態：CONFORMED，2026-10-26。使用者指定依mm3新版方法加速，先選已定位的mode13h 8×8字模常式`1B2E:11A6`。
現有像素命令與RGB合成的CONFORMED範圍保留。32個真實入口在獨立原版CPU的192組完整狀態及有序寫入對照通過，據此審查以下限定契約。

- 從既有正常DEMO記錄真正入口的CPU、堆疊與完整RAM，在獨立dosgolem跑到真正返回，收集完整副作用、像素順序與兩種週期成本。
- 計畫以唯讀資料產生返回暫存器／旗標、堆疊殘值、相容索引寫入、原指令定位及相對步數，不取得機器寫入權。
- 共通層只提交可放入本回合、下一IRQ、畫面及週期事件之前的完整計畫；不足、待發事件、除錯或未支援監看時回原版。
- 原版文字掛勾不在常式內；需另核對地圖取樣、前端輪詢及observer生命週期，不能假設略過多道指令仍逐道通知。
- 成對驗整個CPU、RAM、返回、時間及有序通知，再驗既有正常玩家路線與相同畫面。成本量測含檢查、計畫、相容寫入及通知，不外推整體FPS。

### 字模效果與拒絕條件

正常DEMO觀測2930次入口，PUSH CS加近CALL亦建立相同遠返回框架，不能只接9A遠CALL。
函式93 bytes的SHA-256為`d1c978b914f28d1a978a2cae1b7a1c52f4b5d233176e8bd6c3029b05c9b4958b`。
已證實的完整指令見研究019的IDA段匯出；真正入口資料由`tools/draw_call_probe.go`取得，獨立原版比較為`tools/draw_call_oracle.go`。

輸入為字碼、前景／背景色、文字列及欄，來源為當時DS:9D86的far pointer加字碼×8。
限定40×25文字格、可見mode13h、8 bytes普通RAM來源，拒絕段環繞讀取、堆疊／字型／程式／參數指標重疊及程式簽章失配。
成功產生64個像素及20個堆疊byte writes，保留實際STOSB的CS:IP與相對步數。
每列保留PUSH CX殘值，最後還原DS、BP並far return加10參數bytes，全部暫存器與旗標依原指令效果。
若字模bit總數為N，指令數為656−N，既有週期模型2620−2N，DOSBox-cost為720−N；公式只代表目前dosgolem模型。

### 正式接入邊界

共通規格436限定CALL後提交。CPU只在16位直接／間接近遠CALL完成後提供可選通知，不新增逐指令資格輪詢。
Owner開啟只讀StepView給適配器產生計畫，再核對原版入口通知、事件及回合配額，持有者提交完整CPU／RAM效果。
成功接管時仍依原相對步數發VideoWrite與PIXEL通知；原版索引背板與既有HD來源辨識保留。
未採用的呼叫不改客體；計畫失配或未知條件回原版。適配器錯誤或panic沿既有observer fault處理，不能吞掉。
持有者先以來源適配器提供的入口位址篩選CALL，避免其他呼叫支付來源檢查成本；該入口表以值複製，不暴露機器。
本作開啟印字盤點時回原版，地圖取樣門檻另限制單次預算，不跳過取樣時刻。

驗收含邊界、負對照、事件恰好到期、回合配額、觀測器撤除、兩種週期、近遠CALL及原版完整狀態。
正常重播另比較畫面、閃現、原版CPU／RAM、音訊、DOS檔案及存檔；成對成本含適配器、來源檢查、相容寫入與通知。
