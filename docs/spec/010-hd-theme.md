## 首批接入契約

證據審查：本作 PIC1-131 與 PIC1-043 第 0 幀在已知 DEMO 路徑的 350M、700M 指令畫面，
均與解碼的色號及所有用到的 RGB 色盤完全一致。來源雜湊、解碼偏移與收據見研究 014。
畫面矩形為原版像素 `[24,24,88,88]`，兩者均已證實。其餘 PIC 使用相同格式的結論為強推論。

- 輸入：請求 manifest、來源 `.idx`、768-byte RGB 色盤、通過驗收的 264×264 RGBA PNG。
- 格式維持 `apps/pod/hd.go` 的 `scale:3`、`items` 與 SHA-256 欄位；不新增產品資料格式。
- 主題建置工具只接收來源與輸出雜湊一致、結構分數至少 0.40、色相中位差小於 30 度、全不透明、
  動畫遮罩外差異為 0 的圖。目視驗收另記錄 SHA-256，不以分數取代。
- 原版畫面整塊色號吻合才啟用 watcher；之後依既有 8×8 格失配撤除。找不到素材時回退原版。
- 全程只改呈現；DOS 記憶體、暫存器、色號緩衝、原版資料與存檔不變。無原版存檔格式變更。
- 2 倍不繪 HD；3 倍繪 HD。F2、F12 與規格 021 的首次繪製閃現另作前端抽樣。
- 驗收：相同狀態、步數、按鍵分別跑無 HD／有 HD，原版狀態完全相同；HD 差異限於上述圖面。
  另跑 2 倍與來源失配負對照。正常冷開機 DEMO 與零閃現通過前，不標整份 CONFORMED。

素材只用於現有私人專案與既定 patch 範圍；原版資料不加入 Git。BIGPIC、TITLE、其他圖族與影片維持 DRAFT。
