## 首批接入契約

- 輸入：請求 manifest、來源 `.idx`、768-byte RGB 色盤、通過驗收的 264×264 RGBA PNG。
- 格式維持 `apps/pod/hd.go` 的 `scale:3`、`items` 與 SHA-256 欄位；不新增產品資料格式。

- 原版畫面整塊色號吻合才啟用 watcher；之後依既有 8×8 格失配撤除。找不到素材時回退原版。
- 全程只改呈現；DOS 記憶體、暫存器、色號緩衝、原版資料與存檔不變。無原版存檔格式變更。

- 驗收：相同狀態、步數、按鍵分別跑無 HD／有 HD，原版狀態完全相同；HD 差異限於上述圖面。

素材只用於現有私人專案與既定 patch 範圍；原版資料不加入 Git。BIGPIC、其他圖族與影片維持 DRAFT；TITLE開場見本文後節。
