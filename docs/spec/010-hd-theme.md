# 010 HD 重繪主題

狀態：局部 CONFORMED（2026-10-24；VGA 戰鬥首批與分段呈現保留）；PIC1 條件式整圖辨識維持 READY，其他來源仍 DRAFT。Issue：[#10](https://github.com/wicanr2/pools-of-darkness-cht/issues/10)。
證據：[研究 014](../re/014-vga-hd.md)。前作契約為銀色匕首之謎規格 010；本作 VGA 的來源、色盤與遮擋另驗。

- 維持 960×600 的 3 倍畫布；預設 2 倍顯示原版，HD 只在 3 倍顯示。
- 畫風 B，依原版手繪重畫、原版配色。首批並列圖須經使用者確認才全量。
  使用者已確認 b01 的 BIGPIC1 區塊 243、246，原始生成圖與完整提示詞見 `review/hd/b01-manifest.json`。
- 盤點、請求包、生成、驗收、接入與收據由 Codex 全程負責，使用者於 2026-10-24 確認。
- 請求與輸出 manifest、來源 SHA-256、色盤、尺寸、透明度及權利分類沿用 AGENTS.md 第 6 節。
- 主題沿用 dosgolem `apps/pod/hd.go` 的條件式 watcher；本作色號及來源未驗前不接入正式路徑。
- 失配、撤除或遮擋未知時回退原版。切換不得改動原版記憶體、暫存器、色號或存檔。
- 規格 021 另以本作閃現量尺驗證，不將前作的零閃現視為本作已達成。
- 數值驗收、目視、同狀態與正常玩家路徑通過後，才可稱為遊戲內 HD 截圖。

## 首批接入契約

證據審查：本作 PIC1-131 與 PIC1-043 第 0 幀在已知 DEMO 路徑的 350M、700M 指令畫面，
均與解碼的色號及所有用到的 RGB 色盤完全一致。來源雜湊、解碼偏移與收據見研究 014。
畫面矩形為原版像素 `[24,24,88,88]`，兩者均已證實。其餘 PIC 使用相同格式的結論為強推論。

- 輸入：請求 manifest、來源 `.idx`、768-byte RGB 色盤、通過驗收的 264×264 RGBA PNG。
- 格式維持 `apps/pod/hd.go` 的 `scale:3`、`items` 與 SHA-256 欄位；不新增產品資料格式。
- 主題建置工具只接收來源與輸出雜湊一致、結構分數至少 0.40、色相中位差小於 30 度、全不透明、
  動畫遮罩外差異為 0 的圖。目視驗收另記錄 SHA-256，不以分數取代。
- 原版畫面整塊色號吻合才啟用 watcher；之後依既有 8×8 格失配撤除。找不到素材時回退原版。
- 全程只改呈現；DOS 記憶體、暫存器、色號緩衝、原版資料與存檔不變。無原版存檔格式變更。
- 2 倍不繪 HD；3 倍繪 HD。F2、F12 與規格 021 的首次繪製閃現另作前端抽樣。
- 驗收：相同狀態、步數、按鍵分別跑無 HD／有 HD，原版狀態完全相同；HD 差異限於上述圖面。
  另跑 2 倍與來源失配負對照。正常冷開機 DEMO 與零閃現通過前，不標整份 CONFORMED。

素材只用於現有私人專案與既定 patch 範圍；原版資料不加入 Git。BIGPIC、TITLE、其他圖族與影片維持 DRAFT。

## VGA 戰鬥首批接入

證據審查：[研究 017](../re/017-vga-battle-hd.md)及其固定原始畫格報告。
CPIC 41／64／102 的八個前景鏡像位置、DUNGCOM 5 的第 3／13 影像五個完整位置已逐色號與使用 RGB 證實。
本節 READY 只授權此垂直接入與完整比對的條件式候選，不擴大其他角色、頭身、遭遇與牆面。

- 輸入沿既有 actors／combat 版本 1 清單，3 倍、已驗收 RGBA PNG、原始 idx 與 SHA-256，grid `[8,8,7,7,24]`。
  不新增 JSON 欄位。來源 key 採盤點的 `cpic1-NNN`、`dungcom-NNN@N`、`wildcom-NNN@N`。
- 內部色號計數由 16 擴為 256；出現高色號時必須為已知來源 key 與該圖族允許範圍。
  EGA 來源原行為保持，VGA CPIC 尺寸另允許已盤點的 72×48；既有資訊量與歧義拒絕不降低。
- CPIC 0–15 為保留色、144–255 為來源固定色盤；背景 8 不畫。
  DUNGCOM／WILDCOM 可用保留色及 32–63。其來源區塊色盤雜湊由固定原始輸入建成遊戲專屬索引。
  每幀核對使用的來源色盤區段，失配回退；不同地形區塊同色號不共用錯色 HD。
- 至少三個具資訊完整地形符合才進入戰鬥圖層。怪物完整前景符合後繪製，包含水平鏡像；
  多個候選互相衝突時全退回。來源背景 8 保留底層地形，不把整個矩形覆蓋成灰底。
- 呈現鎖存的色盤簽章涵蓋 256 色；高色號變色後不沿用上一幀舊色 HD。
- 驗收先用真實 `.idx`／`.pal` 與來源資料做怪物、鏡像、背景保留及地形守衛測試；
  加入來源失配、0–15／高色號色盤變更、非戰鬥、2 倍及輸入陣列不變的負對照。
  再跑正常冷啟動 DEMO、F2／F12、原版狀態與存檔差異、首次出圖閃現抽樣。
- 本批六張怪物狀態與兩張地形必須先有數值及最終 PNG 的逐件目視雜湊，才由建置工具接入。
  未觀測狀態只依完整原版輸出選圖，不猜動畫時間；原版仍控制更新、行動、亂數與傷害。

### 戰場分段繪製保留

研究 017 已證實首次像素先於色盤一格，一次移動的局部前景跨6690–6692三格，6693才完整。
本節於 2026-10-24 證據審查後 READY，補上首輪 89 次閃現的缺口。

- 三張完整 VGA 地形色號建立暫緩呈現的範圍，矩形 `[8,8,168,168]`；HD 繪製仍要求原有色盤及場景守衛。
- 3 倍覆繪時，未切好色盤的戰場中剛改變且尚未被 HD／文字替換的 8×8 格，最多沿用先前呈現三格。
  原版單色格也包含在內，避免未切色盤的藍底閃現。
- 色盤就緒後，只保留同一候選至少 144 前景點及三色吻合、該小格全部前景吻合的局部怪物格。
  144 點／三色沿既有資訊量門檻；完整繪圖仍需全部前景。背景 8 不參與局部辨識。
  未知來源立即回退；已辨識局部最多保留三格，不等待猜測中的素材。
- 連續來源變動也最多保留三格，第四格強制回退；色盤改變立即取消舊呈現。F12 與 2 倍直接顯示原版圖層。
- 每個原版畫格只在下一次 Frame 提交最後一份合成結果，同格多次合成須一致。
  原版色號、色盤、CPU、記憶體與存檔均不修改；不修改閃現量尺以使結果通過。
- 驗收重播 6465–6474、6687–6694 格真實來源，保留上限、未知來源、色盤變化及非戰場負對照。
  完整正常冷啟動 DEMO 及 F2／F12 同狀態四路重跑，閃現 0 才接入現行主題。

驗收：dosgolem `f08d961`，相關套件、真實逐格重播與四路正常冷啟動通過。
CPU、記憶體、色號、色盤及127個DOS檔案相同；HD差異只在戰場內，F12原版、2倍及閃現0均通過。
