# 017 我方無敵

狀態：CONFORMED，F1功能抽樣；既有HD遮擋限制另列。Issue：[72](https://github.com/wicanr2/pools-of-darkness-cht/issues/72)，母項[#11](https://github.com/wicanr2/pools-of-darkness-cht/issues/11)。使用者已定案：F1或既有工具列切換，預設關閉，我方HP不減少，避免昏迷、中毒、麻痺、睡眠等異常。固定收據：[029執行期](../re/029-invincible-runtime.json)。

## 本作定位

原版GAME.EXE v1.10 SHA-256為`35ad635e558852925b7028a921aacafc2df8e84be24a8a1136c6267471948d69`，GAME.OVR為`885d6a07a3658f0688dc9d0630dfa984683a3d1d1e515a8e9909d29f62012485`。資料段沿已驗正常SND／CONTROL鏈`DS=2096`。研究入口：[029](../re/029-invincible.md)。

| 原始定位 | 已證實用途與證據 |
|---|---|
| `DS:9CF2`遠指標 | 全隊串列頭；OVR檔案位移0x4E19–0x4E39讀取，0x4EF8–0x4F08取下一筆。`9CEE`是目前角色，不是串列頭 |
| 角色`+0x1E3`遠指標 | 下一筆；正常戰場先三名隊員，再串敵方 |
| 角色`+0xB2` byte | 一般HP；正常ROLAND值40同原版UI，0x16B00–0x16B09拷入戰鬥HP |
| 角色`+0x1FC` byte | 戰鬥HP；0x366EF起原版傷害函式扣除並在致命分支寫健康狀態。不能只保護一般HP |
| 角色`+0x1ED` byte | 健康狀態，0正常；0x2392F–0x23946乘13查`DS:1144`狀態字串表 |
| 角色`+0x1EF` byte | 陣營，0我方、1敵方；沿規格018存活數已驗資料流，正常戰場兩側紀錄交叉核對 |
| 角色`+0x143`遠指標 | 效果串列頭；執行期`179B:00A7`跳板在街上指到`4300:27C1`，與OVR檔案位移0x3665F原始32 bytes相同 |
| 效果節點`+0`、`+5` | 類型byte、下一筆遠指標；0x3665F–0x366CC搜尋端直接讀取，節點九bytes。正常街上0x5F與敵方0x56／0x18／0x25／0x5C作保留對照 |

健康0–8的原版顯示依序為Okay、Animated、tempgone、Running、Unconscious、Dying、Dead、Petrified、Gone。`+0x1EE`是可行動旗標，不是健康狀態；本功能不直接攔截該旗標，以免妨礙正常戰鬥清理。

有害效果只移除本作來源已定位的0x21失明、0x2A緩慢、0x34麻痺、0x35睡眠與0x37中毒。來源字串與呼叫端見029。舊0x1F及0x33未完成本作語意確認，不列入刪除；未知效果保留，不用前作名稱推定。

## 執行契約

- 沿既有session.WriteGuard，不改通用引擎。關閉時不讀寫角色欄位，F1不傳DOS按鍵；偏好不保存無敵狀態，下次啟動仍關閉。
- 原版程式簽章須符合執行期`16AF:01B0`的既有demoMainSignature才讀取串列。不符時不保護、不寫入，不在未知程式猜找角色。
- 全隊串列逐筆檢查位址、完整紀錄界內、Pascal名字1–15個可列印ASCII字元、健康與陣營界限；成環、超過12筆我方或壞指標拒絕整批，遇第一筆敵方正常停止。
- 一般及戰鬥HP寫入變小時立即還原；健康或陣營由0變非0立即還原。治療、回復及其他欄位照常。開啟時不補滿HP，也不復活先前已倒下的角色。
- 每回合開頭先驗證全部我方效果串列，最多64節點；完整檢查通過才解除有害節點連結，保留未知／有益節點及原節點bytes。壞指標、成環、節點重疊角色或跨角色共用節點時拒絕整批寫入。沿前作既有移除策略，不另操作Pascal堆積配置器。
- 原版EXE、素材、亂數與磁碟輸入保持原樣。無敵開啟會刻意改變原版執行結果；玩家存檔可保存被保護後的HP與效果。關閉後不倒扣此前擋下的傷害，不假稱作弊開啟仍同原版狀態。

## 抽驗閘門

1. 本作正常街上與DEMO戰場的角色／敵方來源；原始位移、bytes、輸入SHA與IDA9.4位址空間分列。
2. 兩個HP欄位、健康／陣營、治療與敵方隔離；壞程式、壞串列及有益／未知效果負對照。局部受控測試不冒稱正常玩家路線。
3. 同腳本正常冷啟動及DEMO，關閉時對照現行程式的原版狀態、畫面與客體檔案；開啟抽驗我方HP不下降及敵方仍可受傷。另抽F1開關、回選單與正常載入，不擴大G6探索。
4. 只重建必要前端，原Go繪圖、主題與字型不改；保存工具與固定收據、README操作與限制。舊九包不改寫，私人分支保存後才啟用。

## 抽驗結果

引擎`33094bda183f9656c4be0f821a831b8523319dda`，執行檔SHA-256為`139279d04a43467564599c3e7095dda705781498a7c6f3ebff7920ff7dd8075f`，乾淨Git來源重編逐位元相同。原程式218b60f保留`pod-play-before-invincible`，1536檔主題及十份字型未改。

關閉與啟用無敵各走一條4800格正常讀檔／面板路線，各17張擷取，CPU／RAM、IDX／PAL及132個客體檔案同028。啟用時ROLAND的0x5F效果保留，沒有還原或移除，正常載入與三語切換無缺字；完整視窗唯一新增可見狀態是工具列無敵按鈕。原始121格仍為明示2→3倍切換。

10500格正常DEMO完成F1開關、戰鬥、中斷返回及正常進入選單，記錄5次我方寫入還原、拒絕0。七個受控原版傷害呼叫分開保存：一般10點、等同HP及超額傷害的關閉／開啟對照，以及敵方超額傷害。開啟時我方HP162與健康0維持，敵方仍降至0並死亡。受控fixture明示組合街上已載入程式與戰場角色，不替代正常路線。

正常長戰鬥量尺原始19格，新舊程式同腳本及追加相鄰擷取的事件、原版索引、色盤與疑點格呈現逐點相同。13格為鏡頭移動前單色32空地，下一格換成新牆面；其餘6格保留為既有HD遮擋疑點，不稱零閃現，也不因F1完成關閉#16。重播不是擴大探索，範圍僅疑點相鄰格。

未知效果0x1F／0x33保留；正常劇情中的所有異常施放未窮舉。單元測試涵蓋兩個HP、健康／陣營、治療、敵方及六種完整拒絕；五種有害類型只解除連結，有益與未知節點bytes保留。前端工具列／輸入及vet通過。母項及原案其餘交付仍開啟。
