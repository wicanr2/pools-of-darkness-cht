# 435 延後填入原版RGB

狀態：READY。既有Hold／Latch比較及保存時機、opaque繪圖與字型寫入已逐項審查；保留原入口作獨立oracle。

## 契約

現有Hold／Latch的base為完整最近鄰原版RGBA，用來判斷某格是否仍等同原版，再決定重繪、保留或沿用。
新增可選的不可變索引來源，記錄尺寸、倍率、色號副本與配對色盤；既有Apply入口與行為保留。

新入口允許out的alpha0表示該像素尚未填入原版，alpha255為已畫出的完整RGB。
比較原版時alpha0等同該來源的原版像素，alpha255則逐RGB與來源比較，不以色號相同取代顏色相同。
Hold的歷史畫面同時保存當幀不可變來源，重放alpha0歷史像素時使用歷史色號與色盤，不使用現在的底圖。
Latch沿既有來源指紋／色盤／倍率規則，重放保存畫面時亦還原相應原版像素。混用舊／新入口仍須等價。
最後只為尚未覆蓋像素填入原版RGB，最終RGBA全不透明；已選HD像素不先填原版RGB。
半透明圖不適用此入口，呼叫端需沿既有合成路徑或先確認專屬混色契約。

## 驗收

以既有完整base的Apply作獨立比較，測連續幀、相同色號改色盤、相同RGB不同色號、部分覆蓋、墨跡／非墨跡、
歧義、連續保留上限、無Apply的Commit、多次同幀Apply、模式及倍率改變，包含歷史原版畫面重放與新舊入口混用。
以原版填色計數驗已覆蓋像素不被填入，所有輸出逐像素同舊路徑。此功能預設不改任何現有呼叫端。
