# 022 左右海報

狀態：READY（2026-10-24，實作前審查）。Issue：[#21](https://github.com/wicanr2/pools-of-darkness-cht/issues/21)。
證據與 DRAFT 原型：[研究 015](../re/015-side-posters.md)。使用者已選固定加寬，中央不縮放。

## 邊界與呈現

- 原型寬版的圖面、裁切、配色與字體為基準，見 `review/hd/poster/wide-zh.png`；來源及字型雜湊保留。
- 原版及中文畫布仍是 320×200，2 倍 640×400、3 倍 960×600。只在前端各加原版等效 80 像素寬的海報，
  視窗成為 2 倍 960×400、3 倍 1440×600。中央顯示不變形、不裁切。
- dosgolem `cmd/pod-play` 目前 `Layout`／`SetWindowSize` 為 320×200 乘倍率，`Draw` 只寫遊戲 RGBA；
  `hostInput` 以 `dosPoint` 換座標。海報只改該前端及 `apps/pod` 的呈現工具，不改 session 或 DOS 座標契約。
- 來源是官方商店 1438×810 無字插畫，SHA-256 `7bfb0f23a9d09f5046c0b79b96421f4b1c841f8e97b63c0ec0c248ab7c73d9f0`。
  左右裁切原始矩形分別為 `[520,0,420,810]`、`[900,0,420,810]`，等比填滿，底部漸暗同定版示意。

## 素材與文字

- 使用既有 PNG 格式，不變更原版資料、HD 主題 JSON 或存檔格式。可選海報目錄提供
  `poster-left-2x.png`／`poster-right-2x.png`（160×400）、3x 對應檔（240×600），底圖全不透明。
- 文字唯一正式來源是 `text/poster.<語系>.tsv`，沿用 key／translation／note 欄位；獨立匯出透明 PNG，
  檔名 `poster-text-left.<語系>-2x.png` 等，與對應底圖同尺寸。文字不烘入共用底圖。
- `poster_capture.mjs` 使用同一原型字型與版面匯出圖層，避免另設不同的字型或行距。
- 中文顯示時使用目前語言包代碼，F12 原版顯示時用 en。無該語系文字圖時只顯示無字底圖，清除上個語系文字。
- 未指定素材或沒有完整底圖時維持原視窗。明示載入不完整素材時回報錯誤，不留下部分海報。

## 輸入、截圖與驗收

- 滑鼠先扣掉左海報寬度，再沿既有 `dosPoint`／toolbar／session 路徑。海報點擊不送 DOS，
  原本從中央按下、移到海報放開的情況仍結束拖曳。鍵盤、F2、F12 與遊戲狀態維持原行為。
- 既有 `-shot`、`-shot-original`、F10 的遊戲畫布收據保持尺寸；另以完整視窗收據驗海報。
- 純呈現測試核對中央 RGBA 逐像素相同、兩倍率尺寸、語系切換與缺少語系時清字；輸入測試涵蓋左右邊界及 toolbar。
- 正常冷啟動抽樣 F2／F12、HD DEMO 與海報，原版記憶體、色號及存檔與無海報同狀態一致。
  3 倍合成另與定版原型比較中央與兩側，差異記錄於研究。
- 原版官方插畫的權利分類為本機及目前私人審閱，不加入一般 patch；本功能沒有公開發行授權變更。
