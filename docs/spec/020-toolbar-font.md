## 本作檢查與補齊

`workplace/dosgolem/cmd/pod-play/barfont.go` 已有字級、點擊與偏好處理。
`loadBarFonts` 需要主字型旁的 `pod-rounded-bar12.golemfnt`、
`pod-rounded-bar22.golemfnt`。本輪檢查發現缺少兩檔，會落入最近鄰縮放。
依既有字型契約，以 `tools/font-dev.sh` 從源泉圓體直接產生字模：
12 像素使用 Medium，22 像素使用 Bold，字集取工具列正式文字表。
既有遊戲 16／24 像素字模須保持相同雜湊。

## 驗收

- 正常冷開機至開場標題，抽樣 2／3 倍的全部三級及下拉選單。
- 與固定中字級的同輸入比較，差異只在切換列及下拉選單。
- 原版來源畫面、CPU、完整記憶體及 DOS 檔案保持相同。
- 載入兩個原生字模，確認實際尺寸與字型來源；抽測繁中與英文。
- 點擊選單後核對偏好，重新讀回；無效偏好安全回到中。

字級功能屬前端呈現，無須猜補原版遊戲語意或修改 DOS 程式。

重生入口為 `bash tools/toolbar-acceptance-receipt.sh <新名稱>`。
它在 Docker 內建立隔離前端副本，以 `tools/toolbar_receipt_probe.py` 附加讀值，
並執行 `tools/toolbar_acceptance_test.go` 的正式點擊處理、原生字模與偏好測試。
正常 GUI 另與正式程式作對照，不把點擊函式測試當作作業系統滑鼠驗收。
`tools/toolbar_acceptance_check.py` 比對原版來源、遊戲狀態與影像差異範圍。
README 的字級並列由 `tools/toolbar_font_preview.py` 擷取原始像素，不縮放。
