# 026 遊戲滑鼠與查驗題輔助

日期：2026-11-02。狀態：CONFORMED，功能抽樣，更新封包另驗。Issue：[#79](https://github.com/wicanr2/pools-of-darkness-cht/issues/79)。

使用者同意參考黑暗之后補齊操作。前作只提供方法，本作座標、游標與輸入時機重新驗證。

| 功能 | 契約 |
|---|---|
| 滑鼠 | 原版遊戲區持續接收移動、左鍵與右鍵。2／3倍及海報偏移先轉為320×200邏輯座標。工具列、面板及區外不傳入新按下事件；已按下的按鈕在放開、失焦及離開有效區域後釋放，返回時不補按。 |
| 查驗題 | 預設從本作54題表取得英文答案，僅在本作原版查驗題輸入程序確認後透過BIOS鍵盤填入一次。不送Enter，不改比較、答案、輸入緩衝或磁碟EXE。 |
| 輔助開關 | F9關閉答案顯示與自動填答。開啟時仍不覆蓋玩家已輸入的內容。F12原版顯示模式亦適用同一輔助開關。 |
| 重試 | 原版答錯後重抽的新題重新辨識；離開題目後不再送鍵。未知題目、簽章或輸入狀態不符合時不自動填。 |
| 游標 | 本作原版使用INT33顯示／隱藏，前端由系統游標呈現，位於畫布覆繪之上。保留系統游標，不移植黑暗之后自畫的盾劍游標。 |

證據審查：008的54題、資料段相對偏移及原版呼叫端，與本輪IDA9.4輸入程序0711／0771相符。0711進入後，0771前已建立空的SS:BP-12Bh編輯字串；只有maxLength低位元組為20、返回位移02BE及原版遠呼叫吻合時啟用。原始bytes的遠呼叫在overlay:02B9，02C7是後續字串複製的範圍，不能當返回點。遊戲座標沿mode13h的DOS邏輯像素，原版1D8C:00B1以2除水平回報；沒有前作8倍範圍設定。

驗證採正常冷開機、讀槽A、查驗題及進入遊戲抽樣，另測關閉輔助、人工輸入、答錯重試、區外及失焦清理。新舊封包另行保留。

證據與目前狀態見[研究038](../re/038-input-and-quiz.md)。通用輸入契約另存dosgolem規格437，遊戲位址只放apps/pod。
