# 024 片頭字幕覆繪

狀態：CONFORMED，2026-10-25八組片頭台詞抽樣通過。Issue：[#10](https://github.com/wicanr2/pools-of-darkness-cht/issues/10)。
來源與時序：[研究018](../re/018-movie-subtitles.md)。本規格只處理八組片頭台詞，動畫HD及片尾另計。

## 辨識與生命週期

- 以320×200原版色號畫面底部`[0,168,320,32]`的SHA-256辨識八組來源。不以指令數、播放秒數或前一組台詞推測目前字幕。
- 來源實際只用前景色號7及黑色背景。第四組背景為176，其他組為32。須同時核對背景為黑、前景為灰階且亮度不超過170。
  淡出沿原版前景亮度，不另設計時器、不保留上一句。
- 直接辨識最後呈現的Frame，不快取或延續上一句。尺寸不符、來源失配、顏色失配或缺少目前語言的文字時不覆繪，立即保留原版。
  全黑畫面不顯示文字。此時圖樣是否仍殘留在顯存，不視為玩家可見的字幕。
- 只讀原版畫格及色盤。不得修改DOS記憶體、原版檔案、輸入、亂數、播放速度與存檔。

## 顯示與語系

- 文字沿既有`text/host-text.<語系>.tsv`，鍵`intro.001`至`intro.008`。英文也從表中取得，不在Go程式寫台詞。
- 使用目前語系的正式字型及既有換行函式，每行最多38格、最多4行，置中於原版字幕區。超出或缺字時整組退回原版，不能截斷台詞。
- 繁中與英文均支援2／3倍；F8在同一來源立即換語言，F12立即呈現原版。字幕與HD素材開關獨立。
- 畫面差異只允許在底部32列。中央動畫、邊框及音訊不變。不把英文字幕視為已完成其他英文面板。

## 驗收閘門

1. 正常常駐驅動與CONTROL鏈冷啟動，不送跳過鍵，逐幀記錄首次出現、淡出與清除。包含全黑色盤的色號轉換。
2. 來源八組及所有觀測淡出狀態，2／3倍、繁中／英文、缺字與來源／色盤負對照，差異須在字幕區內。
3. 同一初始狀態與輸入的正常視窗路徑，原版CPU、記憶體、色號、色盤及DOS檔案一致。F8／F2／F12不送入DOS。
4. 沿既有閃現量尺量測0，並用延後一格覆繪建立可偵測的正對照。全黑色盤不得冒充原字已可見的證據。

首次繪製與清除證據見[018-intro-timing.json](../re/018-intro-timing.json)，先達READY後實作。
正常視窗驗收見[018-intro-runtime.json](../re/018-intro-runtime.json)：5100格、八組首次可見畫格及淡出清除、F8／F2／F12通過，閃現0。
兩條正常路徑的CPU、記憶體、色號、色盤及127個DOS檔案一致，且與只讀來源探針終點相同。
實際來源畫格另驗繁中／英文各2／3倍、來源與色盤失配、缺字回退；延後一格的正對照能被既有量尺抓到，未改量尺。
只涵蓋八組INTRO字幕，不包含片尾、動畫HD或其他版本。
