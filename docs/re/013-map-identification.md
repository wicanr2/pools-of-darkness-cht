# 013 GEO 地圖名稱與攻略圖例辨識

日期：2026-10-24。Issue：[#9](https://github.com/wicanr2/pools-of-darkness-cht/issues/9)。
狀態：本輪名稱與五個攻略點的證據審查、接入及抽樣驗證通過；全案仍有下列缺口。接續[研究 012](012-map-overlay.md)與[規格 009](../spec/009-map-overlay.md)。

## 範圍

比對本作 32 塊 GEO 與 SSI 英文提示書、軟體世界第 43–45 期的地圖牆面，
為有充分證據的地圖加入名稱與攻略圖例。沿用既定文字及地圖資料格式，不增加自動探索。
尚未辨識的資料留在研究工作區，沒有足夠證據的名稱或格子不接入正式表。

來源仍為研究 002 已取得的 `workplace/input/en-docs/mocagh/pod-hintbook.pdf`，
SHA-256 `1e63d7fa7bf7ad10460135a15642f621a5879bc452d2a428d7f7d20eabdf14f2`；
`GEO1.DAX` SHA-256 `d628bae8349044a1c1c05b821ccfbba6464ed5bfa57cef15ca05ec52cc5afc1f`。
工具輸出與原始參考圖片放 `workplace/geo-reference/`，不進 Git。
研究工具為 Python 3.13.16、Pillow 11.0.0、Poppler `pdftoppm` 22.12.0。
沿用 `sosb-img:r1`（`8b9012adb991`）、`cok-pdf:bookworm-r1`（`05e99381d00a`）及 dosgolem Go image，沒有重建工具鏈。

## 已排除的方法

圖例號不能直接當作 GEO 第三平面的值。工具的 `event plane` 僅供格式導覽，原版如何解讀該平面仍未驗。
已證實的訓練廳圖例 3，在 (6,3)、(7,3) 的值是 `0Bh`；
提爾修院圖例 13 在 (13,3) 為 `04h`，在 (12,3) 為 `A8h`。
這些數值屬 GEO 解碼後本體的 `200h+y*16+x`，不是執行期位址；原始資料平面保留，不作猜測性改名。

## 牆面辨識與採用範圍

提示書每個 PDF 頁面含兩張印刷頁。本輪 `pdftoppm -png -scale-to 1800` 產生參考圖；
PDF 第 9 頁對應印刷 p.13–14，後續每張加兩頁。
[裁切表](013-map-reference-crops.json)只記圖名、PDF 頁、像素矩形與格數，不含原版圖片。

- [map_reference.py](../../tools/map_reference.py) 畫出全部 32 塊的四方向牆面與事件值。
- [map_match.py](../../tools/map_match.py) 比較參考圖格線與 GEO 牆面，輸出前五個候選。
  分數是預期有牆與無牆位置的平均墨色密度差，只作排序；不以分數自動接入。
- 人工對照提示書、四張 GEO 圖集與候選座標後，採用下表名稱。等級「已證實」限靜態牆面與印刷圖的對應，
  不表示已跑到該地，也不表示事件、樓層切換或攻略點已驗。
- 座標基準是 GEO 解碼後的 16×16 格，左上 (0,0)，x 向右、y 向下。區塊號以十六進位表示。

## 可重生入口

在既有 `sosb-img:r1` 容器執行下列 Python 命令；提示書轉圖使用既有 `cok-pdf:bookworm-r1`。
原始輸入唯讀，圖片與候選 JSON 僅寫 ignored 的 `workplace/geo-reference/`。

```text
python -I tools/map_reference.py --orig workplace/input/dos/pod --out workplace/geo-reference
python -I tools/map_match.py --orig workplace/input/dos/pod --refs docs/re/013-map-reference-crops.json --images workplace/geo-reference --out workplace/geo-reference/matches.json
python -I tools/map_geo.py --orig workplace/input/dos/pod --titles text/map-titles.tsv --guide text/map-guide.zh-TW.tsv --out text/map-geo.tsv --check
```

接入前已核對出處、牆面形狀、座標基準及既定譯名。字型與同狀態收據結果見下節。

## 攻略專名對齊

三份自寫摘要與 78 段正式攻略表沿用既定譯名，新增 32 個地名詞組或拼法別名到 `text/glossary.tsv`，合計 981 筆。
新增詞以既有專名組合，如「馬可斯之塔」、「提爾神殿」；普通小據點以英文名稱直譯。
`Fire Giant's Care`、`Kalites' Parlor` 保留為雜誌拼法別名，分別依 SSI 的 Cave、Kalistes 校正玩家可見名稱。
沒有藉本輪名稱辨識改寫攻略的事件、規則或原有證據限制。

[walkthrough_terms.py](../../tools/walkthrough_terms.py) 只對完整英文詞組查術語表，保留英文括註、未知詞組與操作指令。
替換後的實際片段已人工校讀，並重建 `text/walkthrough.zh-TW.tsv`。
檢查入口 `python -I tools/walkthrough_terms.py --check` 與既有 `tools/term_check.py text`，皆在 Docker 內執行。
物品與指令的未對齊片段仍有保留，不宣稱全攻略已完整校譯。
馬可斯章原有的「雷姆斯大地」依既定 `Realms → 王國` 一併修正。

## 驗證結果

- `map_geo.py --check`：32 塊、24 個 GEO 名稱、五個攻略點共七格通過。
  錯誤象限數、同一圖例多格卻不同摘要的兩個負對照均拒絕。
- `walkthrough_terms.py --check`、`term_check.py text`：通過；981 個英文術語鍵不分大小寫仍唯一，78 段標題格數符合面板上限。
- 字型重建各 2,843 字，Unifont 補字 0；12 份正式顯示表在兩種字型均缺 0 字。
  16×16 SHA-256 `0f0430e7db828b8b74249b69f02ac7c590724215d9edc0f212830790ae4531ac`；
  24×24 SHA-256 `52e749e344c5bf6a60fa6501ad4ab17b72de0871897382a5c58d2acc3cc21730`。
- `go test ./apps/pod/...` 通過；八份真實記憶體測試另以 `-count=1` 明確重跑，全部通過。
- `tools/g8-map-receipt.sh east` 與 `west`：兩城、兩倍率、原版／走過／全圖，共 12 張。
  每組原版色號、完整記憶體、暫存器與 scratch 相同，面板外差異 0、缺字 0。
  東菲蘭 3 倍與西菲蘭 2／3 倍全圖已目視核對，座標、招牌、圖例與隊伍箭頭相符。
- 第 52 段「馬可斯之塔」攻略另抽驗 3 倍版面，面板外差異 0、缺字 0，已目視核對。
  這是既有正常路徑狀態的顯示抽樣；本輪未新增冷開機路線或實體鍵盤試玩聲明。
- 本機 `workplace/geo-reference/receipt.json` 綁定地圖資料、攻略、術語、兩份字型、執行檔與這 13 張顯示圖的 SHA-256。
