# 035 片尾FINAL來源與HD

2026-11-02。Issue：[77](https://github.com/wicanr2/pools-of-darkness-cht/issues/77)。片尾播放器的HD接入與抽樣通過。契約見[規格010](../spec/010-hd-theme.md#b48-片尾final)，來源與執行期分存[035來源](035-final-source.json)及[035驗收](035-final-runtime.json)。

FINAL.BMA為253780 bytes，SHA-256為`23c487072f64b7dd9850db885bf55a8713a289e9f5f94703b802de7bcc50f5b1`。沿[已驗BMA解碼器](../../tools/intro_bma.py)逐位元組核對六區塊、58圖，圖數依序6、12、5、3、30、2。各圖為320×200，上方320×168為美術，下方32列另查字幕。

原版VACE內建使用說明提供`VACE VideoMode AceFile VideoFlag SoundFlag`，VGA為4。CONTROL.EXE含` FINAL 1 `呼叫片段。研究以既有ADLIB常駐、虛擬路徑C:\POD\SND.COM及監督佇列`VACE.EXE 4 FINAL 0 1`直接執行原版播放器。0表示播放器自行切換顯示模式，與CONTROL已備好模式的1分開記錄。這是片尾播放器直接入口，沒有重播完整通關。

[來源探針](../../tools/final_bma_probe.go)只讀VGA圖格入口，核對VGA.DRV的255-byte既有簽章與完整BMA區塊SHA。實際DOS執行期位址為46EB:6733，與片頭CONTROL鏈的48A1:6733分開記錄；檔案位移為VGA.DRV 0x6733，不能混用位址基準。

[來源與請求盤點](../../tools/final_hd_inventory.py)核對原版呼叫順序、圖格與slot2／x0／y0／flags0，保存實際色盤與完整來源／寫入前綴。首次探針在播放器正常退出後繼續索取View而停止，已依session生命週期修正，乾淨重跑至正常退出；初次失敗只屬探針問題，原版未改。

[審閱頁](../../review/hd/b48-final/README.md)保存七次生成紀錄、43張成品、數值驗收及綁SHA目視紀錄。結構分數至少0.4、色相中位差小於30度，未變更閾值。城市顯露改用原版稀疏線條遮罩，修正早期遮罩膨脹造成的提前完整顯露。

引擎`3fdeeb8ddd93ca84ee3626bc357dc2586c814883`在`apps/pod`共用已驗BMA規則，FINAL另存觀測與重設狀態。來源須完整吻合簽章、參數、區塊SHA、索引及已觀測色盤。可重定位簽章只在一般RAM檢查，ROM及界外位址拒絕；片頭原CS守衛保持。失配回退，F2二倍與F12旁路，不改客體記憶體或存檔。

缺少整份`final.json`時，既有主題仍能載入，片尾保持原版。已登記素材遭損壞、缺PNG或雜湊不同時，沿既有主題契約拒絕載入，不把主題錯誤當作來源回退通過。

## 驗收

- 原樣、HD及切換路線各2001格、192,596,250步。CPU、RAM、索引、完整色盤及127個DOS客體檔案相同，亦與未啟用HD的x86來源探針終點相同。
- 58次來源呼叫全數辨識。83張截圖逐張核對三側來源，其中70張完整HD逐像素對上成品與亮度，另有12張前綴及一張全黑轉場。下方32列全部不變。65份實際來源的元件測試另核對完整圖、前綴、清零及失配。
- F8驗證五語海報，中央圖面保持。F12及F2二倍逐像素吻合原版，恢復三倍後回到HD。HD原始閃現量尺0；切換路線546格只落在預先指定F2的459→460回合，逐格保留於收據，非預期0。
- 正式CONTROL入口7400格正常DEMO的原版狀態、127檔及B版完整視窗SHA同既有基準，閃現0。Go測試與vet通過。正式與測試播放器由乾淨引擎Git重編，逐位元相同；兩者只有已記錄的啟動佇列差異，測試入口不加入產品操作。

原版播放器在2002回合退出；GUI在2001回合保存終點，另由原版探針保留完整正常退出。早期2200格GUI因退出早於收據保存而沒有終點，只留診斷。缺DISPLAY及7400格逾時也屬測試環境問題，改用Xvfb與足夠時限重跑，不當作產品缺陷。
