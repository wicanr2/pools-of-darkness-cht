# 030 長戰鬥遮擋與擷取時點勘誤

日期：2026-11-01。Issue：[73](https://github.com/wicanr2/pools-of-darkness-cht/issues/73)，母項[#16](https://github.com/wicanr2/pools-of-darkness-cht/issues/16)。本切片已完成來源審查、修正與正常DEMO抽驗。原始擷取沿[029](029-invincible-runtime.json)，[來源收據](030-hd-occlusion-source.json)與[正常收據](030-hd-occlusion-runtime.json)分開保存。本機診斷輸出在`workplace/probe/hd-occlusion-v1/`。

## 029分類勘誤

原有13格「鏡頭變更」分類有誤。`cmd/pod-play/main.go`的Update先遞增frame，再於apply處理actShot，之後才Advance及AuditFlash。因此腳本截圖標號N對應該次推進前的N−1呈現，量尺N的對應擷取是N+1。原版索引與PNG本身配對正確，錯的是把檔名N直接對到量尺N。

正確對齊後，量尺8191→8192使用`pod-f008192`與`pod-f008193`。13個格在前者均逐點等於原版RGB，後者均被HD替換；來源也須依這一對比。這已反證029的13格誤判分類。另六格須對齊8196／8197及8899／8900，補齊缺少的相鄰擷取後驗證。原始029收據與當時工具不改寫，保留歷史並以本勘誤取代其分類結論；F1前後同腳本及原版狀態比較不受此勘誤影響。

## 已確認原因

既有COMSPR呈現要求完整24×24含背景色號8吻合。但正常擷取中，COMSPR019在16,24等格間位置的177個非8前景點完整吻合，背景8的位置仍保留原地形；COMSPR133在104,80的139點也完整吻合。這條實際路徑將8作透明背景，因此原完整矩形比對沒有接住。地形則因被特效蓋住而失去整張24×24比對，怪物同樣可能被特效遮住而撤除。

來源是本專案正式1536檔主題與正常DEMO擷取，執行期引擎33094bd、程式SHA-256 `139279d04a43467564599c3e7095dda705781498a7c6f3ebff7920ff7dd8075f`。診斷以Go overlay讀取原始索引／色盤，完整核對前景，沒有修改原版程式、畫面或資料。上述透明背景語意為本次來源已證實；尚未確認的圖層與歧義仍保留原版。

修正以完整合成來源為準：已知特效的全部前景必須吻合；其餘可見地形／怪物來源也必須吻合，遮擋只來自已驗證前景。任意異色不作遮罩，四格保留上限及量尺維持原值。證據審查後依[規格010](../spec/010-hd-theme.md#戰鬥透明特效與合成來源)的READY契約實作。

## 來源與驗證

- 輸入是正式1536檔主題、正常DEMO的320×200色號索引及256×3色盤。索引位址基準為`y*320+x`；擷取標號是推進格數加一。來源檔名、SHA-256、HD PNG雜湊及可見點數逐筆保存在來源收據，沒有引用未分級的原版位址語意。
- COMSPR019在擷取8192、8193、8196的透明前景完整吻合；COMSPR133在8899鏡像吻合。133下方CPIC102有172點可見前景、127點被已證實特效遮住，可見部分完整吻合。地形另須逐點符合其餘可見來源且候選唯一。這些樣本為已證實，其他來源歧義保留原版。
- 既有完整CPIC下的地形可獨立辨識，不能等待其他位置出現特效才啟用，否則不相關位置會隨特效出現而替換。四處前後共八個正常來源核對此隔離。
- 擷取8211的格間COMSPR138使用原有144點／三色及完整8×8格的暫留條件，搜尋格距由24改為8。擷取8751的小型COMSPR005只有上八列完成，24×8全部192點符合唯一來源前綴與色號32平地，共七色。此完整前綴只取得既有四格暫留資格，不繪局部HD。第五格強制回原版，沒有延長等待。
- Go來源測試核對直接／既有合成、F12、二倍、重複呼叫、輸入不變，以及來源改點、色盤、清除、特效／CPIC／地形歧義等11類負對照。小型前綴另驗未知背景、三組色盤、歧義與清除。Pillow及numpy獨立讀索引、色盤及正式PNG，不沿用Go匹配清單；四個畫面的HD像素失配與核准範圍外差異皆0。

工具為Go 1.24.13、`dosgolem-go-ebiten:1.24-r1`（`8ed6bdee2bce`）與`sosb-img:r1`（`8b9012adb991`）。Go負責編譯及測試，影像映像負責numpy／Pillow核對；兩者不混用runtime。來源與原始資料只讀掛載。
