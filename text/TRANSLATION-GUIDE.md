# 翻譯指引

《Pools of Darkness》（中文名《黑暗之池》）繁體中文化的翻譯規則，改寫自銀色匕首之謎 `text/TRANSLATION-GUIDE.md`。
每個翻譯批次開工前先讀本檔、[`glossary.tsv`](glossary.tsv) 與 [`term-avoid.tsv`](term-avoid.tsv)。譯名優先序與文風的定案來源見
`AGENTS.md` 第 3.3 節。

本作是 Forgotten Realms 系列 Gold Box 第四部，接在《光芒之池》《青色枷的詛咒》《銀色匕首之謎》之後。隊伍十年來四處對抗邪惡，
屢次挫敗班恩，這次搭船回到菲蘭城，城市在隊伍當年擊敗泰蘭特拉克斯後重建繁榮（英文手冊 Introduction）。開場旁白說，班恩一心復仇，
把最強的力量投向王國，外層位面的生物也與隊伍為敵（`ECL1` 區塊 4）。

## 文風

- 忠實正式，奇幻古典語氣。貼近原文語意，不增刪情節，不加註解。
- 原文全大寫是字型限制，不代表喊叫；依語意判斷語氣。
- 粗俗或口語的角色（盜賊、酒客、怪物爪牙）譯成自然的口語，不用方言字。
- 引號：原文的 `'…'` 對話譯成「…」，引號內再引用用『…』。
- 標點用全形：，。！？：；「」『』（）……。不用全形空白。
- 用字依教育部常用字：「裡」不寫「裏」（手札譯文全用「裡」；前作兩者混用，不沿用）。

## 術語

- 專名一律依 `glossary.tsv`；`term-avoid.tsv` 列的舊譯（黑精靈、半蜘蛛人、黑夜之卵等）不得出現。
- 法術、怪物、物品名與銀色匕首之謎一致（使用者 2026-10-23）：術語表已是前作譯名，前作沒有的才用珍157 或自譯。
  珍157 說明書的名稱（例「火球術」「束縛敵人」）不要用，裁定見 [`zh157-names.tsv`](zh157-names.tsv)。
- 表內沒有的專名，依序參考珍157 修正後的手札（[`journal.zh-TW.tsv`](journal.zh-TW.tsv)）、光芒之池說明書譯名
  （`/home/anr2/cht/golden_box/pool_of_radiance/docs/reference/manual/glossary.md`）、青色枷的詛咒譯名
  （`/home/anr2/cht/golden_box/curse_of_the_azure_bonds/docs/knowledge/coab-glossary.md`）；都沒有就自行音譯或意譯，
  批次輸出的 note 欄寫「新詞：英文=中文」，合併時收斂進術語表。
- 克萊恩世界（克萊恩英豪、幽靈騎士、黑暗之后）的人名、地名、神祇不沿用；遊戲機制與共通物品可沿用。
- 同一英文專名在整個遊戲只用一種譯法。前作題名：《光芒之池》《青色枷的詛咒》《銀色匕首之謎》；正文裡的 Silver Blades 團體作「銀刃」。
- 劇情裡的 Pool(s) of Darkness（通往異界的黑暗池子）也作「黑暗之池」，與題名相同；一般的 pool 作「水池」。
- 手札以編號稱呼時寫「手札第 N 則」。
- 遊戲機制詞（AC、THAC0、HP、等級）依術語表；表內沒有的保留英文縮寫。
- 物品名的加值放在後面，例「長弓 +3」。

## 硬規則

- `key` 一字不改，列數與順序與輸入批次相同。
- 譯文單行，不含 tab、換行、控制字元；頭尾不留空白。
- 原文是雜訊（不成句的位元組、亂碼、程式碼殘渣、截斷的半句重複片段）時，譯文寫 `-`，該列不進正式檔。
- 原文被拆成多則接續的片段（看 `prev`、`next` 欄）：譯文要能依原順序接起來讀通。片段開頭若接在名字或前一句之後，
  不要另起主詞；必要時把語意放在較完整的那一則，另一則譯短。
- 數字、角色名、物品名若出現在原文中，照原樣保留在對應位置。
- 玩家必須輸入的字（密語、謎語答案）寫成「中文（ENGLISH）」；遊戲只接受英文輸入，不改判定。英文雙關謎語附英文原句與答案。
- 敘述對玩家隊伍用「你們」；NPC 對白依語境，對單一對象可用「你」。
- `ECL1` 區塊 1–3 是開發用的跳關與戰鬥測試選單，照字面短譯即可。

## 介面字串

- 介面字串（選單、狀態、職業、法術名）要短：中文字數不超過英文原文字元數，越短越好。
- 不加熱鍵標記，熱鍵由程式另外處理。
- 字串前後的空白補位不譯。
- 介面來源是從執行檔抽出的字串，不少是位元組雜訊（例 `789:;<=>?@ABCDEG…`、`Z[U`OaP[^`ZU`）、執行環境錯誤訊息或格式表；雜訊寫 `-`。
  `$` 照原位置保留（推定是 DOS 印字功能的字串結尾）。

## 輸出格式

每批輸出 `done/batch-NN.tsv`（UTF-8、tab 分隔），表頭：

```
key	translation	note
```

note 只寫需要人工確認的事：新詞、不確定的語意、接句困難。沒有就留空。
