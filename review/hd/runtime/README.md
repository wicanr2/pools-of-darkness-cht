# 正式主題的重建素材

本目錄補存19張原先只在本機的開場／海報PNG，以及17份原樣主題JSON。
其他657張PNG沿用[既有審閱頁](../README.md)，由[manifest.json](manifest.json)按SHA指向實際Git檔案，避免重複保存整套圖片。

請依[SETUP.md](../../../SETUP.md)重建。664份原版辨識索引由自備DAX重生，不放在本目錄。
目前清單對應b41的1357檔主題。缺素材、雜湊不同或原版版本不合時拒絕重建；不從舊`workplace/`猜補。

`images/posters/`含原版插畫的私人審閱圖，沿既有權利例外保存。其他圖為已接受HD成品。這些檔案不改變儲存庫可見性、發行方式或公開散布權利。
