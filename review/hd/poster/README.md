# 左右海報示意

狀態：使用者於 2026-10-24 確認固定加寬版面；以下寬版圖為實作基準。[Issue #21](https://github.com/wicanr2/pools-of-darkness-cht/issues/21)。

使用 Steam 官方商店的無字背景插畫，左右分別裁取不同人物；中央使用本作既有實際執行截圖。
海報文字獨立於底圖，依繁中／英文示意切換。[開啟互動示意](prototype.html)。

兩種版面供比較：左右各 240 像素、中央維持 960×600；或只使用 16:9 畫面的餘白，每側 53 像素，過窄時不放文案。
原型尚未改動遊戲視窗、輸入或正式素材。來源與 SHA-256 見 [manifest.json](manifest.json)。
